# 🍕🌭🍔🥪 Food Selection System with Python

This project is a simple food selection program designed and developed using the Python programming language.

In this program, users can choose their favorite food from three available options.

## 🚀 Features

- Pizza selection
- Burger selection
- Fried Chicken selection
- Receiving user input
- Displaying the selected food
- Validating user choices and displaying an error message for invalid inputs

## 🛠️ Concepts Used

- Variables
- Getting user input using `input()`
- Conditional statements: `if` and `elif`
- `else` statement
- Comparison operator: `==`
- Displaying output using `print()`

## ⚙️ How the Program Works

First, the program displays a list of available food options to the user.

The user enters the name of their preferred food. Then, the program checks the user's choice using conditional statements and displays the selected food if the input is valid.

If the user enters an option that is not included in the available choices, an error message will be displayed.

## 🎯 Project Objective

The main goal of this project is to practice conditional statements, user input, and basic decision-making structures in Python.
