# Food
# 🍕 سیستم انتخاب غذا با زبان پایتون

این پروژه یک برنامه ساده برای انتخاب غذا است که با استفاده از زبان برنامه‌نویسی Python طراحی و پیاده‌سازی شده است.

در این برنامه، کاربر می‌تواند از بین سه گزینه غذایی، غذای موردنظر خود را انتخاب کند.

## 🚀 قابلیت‌های برنامه

- انتخاب پیتزا (Pizza)
- انتخاب برگر (Burger)
- انتخاب مرغ سوخاری (Fried Chicken)
- دریافت انتخاب کاربر
- نمایش غذای انتخاب‌شده
- بررسی انتخاب‌های نامعتبر و نمایش پیام خطا

## 🛠️ مفاهیم استفاده‌شده

- متغیرها (Variables)
- دریافت ورودی با `input()`
- دستورات شرطی `if` و `elif`
- دستور `else`
- عملگر مقایسه‌ای `==`
- نمایش خروجی با `print()`

## ⚙️ نحوه عملکرد برنامه

ابتدا برنامه فهرستی از گزینه‌های غذایی را به کاربر نمایش می‌دهد.

کاربر نام غذای موردنظر خود را وارد می‌کند. سپس برنامه با استفاده از دستورات شرطی، انتخاب کاربر را بررسی کرده و در صورت معتبر بودن، نام غذای انتخاب‌شده را نمایش می‌دهد.

اگر کاربر گزینه‌ای خارج از موارد تعریف‌شده وارد کند، پیام خطا نمایش داده می‌شود.

## 🎯 هدف از ساخت پروژه

هدف از این پروژه، تمرین دستورات شرطی، دریافت ورودی از کاربر و آشنایی با ساختار تصمیم‌گیری در زبان برنامه‌نویسی پایتون است.
